The idea

Background

Networks need both the flexibility of learning and the precision of explicit rules.

A language model can capture complex traffic patterns and still generate impossible packets. A learned controller can perform well on average and still waste available capacity. Neurosymbolic network management gives learned systems a layer of knowledge they can act on.

Symbolic Components in Network Intelligence

Symbolic knowledge states requirements we can inspect and check, from link capacity to valid packet fields.

Rules can guide what AI generates, focus testing on realistic inputs, and correct decisions during deployment.

01

Logic-guided Generation

Generated network data should follow the same rules as the network it represents.

LeJIT: a case for Just-In-Time knowledge infusion

A language model learns statistical patterns in network data. LeJIT uses a logical solver to exclude choices that would violate explicit requirements, while leaving the language model to choose among the valid options.

LeJIT · HotNets 2025

Zoom2Net: a case for knowledge-augmented training

Coarse measurements can hide short traffic bursts. Zoom2Net learns correlations among network signals to reconstruct fine detail. Explicit constraints keep the reconstructed telemetry consistent with measurements and operational knowledge.

Zoom2Net · SIGCOMM 2024

02

Logic-guided Testing

Useful tests must describe traffic that could actually reach the deployed system.

PANTS

Adversarial search can propose input features that fool a network classifier, yet correspond to impossible traffic. PANTS combines that search with a solver that constructs realizable packets. It then checks whether those packets still fool the classifier.

PANTS · USENIX Security 2025

An attacker restricted to delaying packets cannot make them arrive earlier.

03

Logic-guided Control

Explicit rules turn observed behavior into knowledge that can guide future decisions.

NetNomos: a case for automated rule learning

Network knowledge is scattered across standards, measurements, and operator experience. NetNomos learns candidate rules directly from data, filters them for meaning, and enforces them during generation.

NetNomos · NSDI 2026

ReGuard: a case for rule-protected RL controllers

A poor outcome does not always mean the controller made a poor decision. ReGuard searches for conditions where better decisions could have achieved more. It turns those counterfactual examples into rules that correct recurring mistakes during deployment.

Looking ahead

The research agenda

Network AI needs knowledge it can inspect, update, and use at the right moment.

Discover meaningful rules

Distinguish recurring relationships from coincidences and express richer behavior over time.

Make reasoning efficient

Integrate learning and constraint enforcement so that explicit knowledge can guide decisions under tight latency requirements.

Keep protection useful

Find new failures and update the rules as networks and workloads change.
